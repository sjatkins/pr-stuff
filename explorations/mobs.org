* What a mob is
:PROPERTIES:
:CUSTOM_ID: what-a-mob-is
:END:

A mob is a =char_data= like a player, with =ACT_ISNPC= set and no
connection (unless an immortal has switched into it). There is no
separate mob struct; the player-only and mob-only fields live side by
side in =h/structs.h=. Fields that matter only for mobs:

| field              | meaning                                                      |
|--------------------+--------------------------------------------------------------|
| =vnum=             | the prototype it was loaded from                             |
| =act=              | behaviour flags (=ACT_*=, below)                             |
| =default_pos=      | position it returns to when idle                             |
| =default_zone=     | zone it was loaded into, for =ACT_STAY_ZONE=                 |
| =group_with=       | vnum of a mob it joins as follower if seen                   |
| =hatefield=, =hates= | what it hates by category, and a list of individuals       |
| =fearfield=, =fears= | same for fear                                              |
| =persist=, =old_room=, =last_direction= | hunting state                             |
| =pulse_count=      | incremented on each think; drives the "every Nth think" cycles |
| =sounds=           | ambient sound text, played at random                         |
| =skills=, =spells= | lists used by =mob_attack= to pick special attacks           |
| =wait=             | lag, consumed a second at a time by the think event          |

Prototypes live in =mob_db=, a hash of =index_mem= keyed by vnum, each
holding the prototype =char_data=, counts (=world_count=, =game_count=,
=num_destroyed=), limits (=max_exist=, =zone_limit=) and an optional
special-procedure pointer =func=. =real_mobp(vnum)= fetches one.

* Loading and limits
:PROPERTIES:
:CUSTOM_ID: loading-and-limits
:END:

Mobs enter the world only through zone resets ([[file:rooms.org::#ageing-and-reset][rooms, "Ageing and reset"]]; =zone.c=, =reset_zone=
→ =perform_commands=), at boot and then whenever a zone's age reaches
its reset frequency (always, or only when no players are in it). A
zone's command list says which mob loads in which room, with optional
equipment, inventory and chained loads (=M=, =O=, =C=, =G= for group,
=L= for load, =I= for in-container), subject to the prototype's
=max_exist= and per-zone limits. Counts are recomputed before each
zone pass (=clear_count= over =mob_db=).

On creation (=mobdb.c:367=) a mob gets its first think event at a
random 1 to 1,200 pulses, and like every character a per-tick update
event (=limits.c=): regen of hit, mana, power and move, hunger and
thirst changes, suffering damage when incapacitated. So mobs heal
between fights on the same schedule players do.

* The think: what triggers a mob
:PROPERTIES:
:CUSTOM_ID: the-think-what-triggers-a-mob
:END:

Nothing happens to a mob because a player /arrived/. Mobs act from
exactly two sources:

1. Their own think event, =EVT_MOBILE=, about once a second
   (=mobact.c=, =event_mobile= → =act_state=).
2. A player's command in the same room, which runs the mob's special
   procedure /before/ the command executes (=interpreter.c:289=,
   =special()=), and =tell= to a mob, which goes straight to its
   special.

So reaction time to a player walking in is "the mob's next think that
takes the relevant branch": within a second for a hateful mob that
remembers them, within about four for an aggressive one, never for a
plain one.

** The decision list (=act_state=, =mobact.c:180=)
:PROPERTIES:
:CUSTOM_ID: the-decision-list
:END:

Evaluated in order every think; the first branch that acts wins.

1. If =group_with= is set and that mob is here, become its follower.
2. If fighting someone who is no longer in the room, stop fighting.
3. If =ACT_SPEC= and the prototype has a special, call it with
   =SPEC_IDLE=, or =SPEC_FIGHT= every third think while fighting; if
   it returns true, done.
4. Every 20th think, =DecayHatred=.
5. Do nothing while lagged (=wait=), charmed, paralysed or confused.
6. =ACT_HEALER=: heal self or friends every =PULSE_HEALER=.
7. If fighting: =act_fight= ([[#in-a-fight][below]]).
8. If =ACT_HUNTING=: one step of =MobHunt= ([[#hunting-chasing-across-rooms][below]]).
9. If aggressive (=IS_AGGR=: =ACT_AGGRESSIVE= and not calmed), every
   4th think: =act_aggressive=.
10. Standing: =aid_friends=, join a fight on the side of a mob with the
    same vnum or in the same group.
11. Awake, every 4th think: scavengers that are not humanoid pick up
    items. Humanoids: =spread_hatred=, and on a 5-think cycle
    =find_items= then =discard_items=.
12. =maintain_pos=: return to =default_pos= (wake, stand).
13. =ACT_HATEFUL=: attack anyone present it hates.
14. =ACT_AFRAID=, every 10th think: flee from anyone present it fears.
15. Not =ACT_SENTINEL=, every 5th think: =mobile_wander=.
16. =ACT_GUARDIAN=: stay with master.

Several branches =sendf= debug text to the mob ("Attacking X",
"wandering...", "Not acting aggressive because I'm wounded more than
my enemy"); it is visible only to an immortal switched into the mob.

* Behaviour flags (=ACT_*=, =h/const.h:777=)
:PROPERTIES:
:CUSTOM_ID: behaviour-flags
:END:

| flag             | effect                                                                 |
|------------------+------------------------------------------------------------------------|
| =ACT_SPEC=       | has a special procedure; run it on think, fight, commands, death     |
| =ACT_SENTINEL=   | never wanders                                                          |
| =ACT_SCAVENGER=  | picks up objects lying around                                          |
| =ACT_ISNPC=      | it is a mob (set on all)                                               |
| =ACT_NICE_THIEF= | thief special does not attack                                          |
| =ACT_AGGRESSIVE= | attacks players on sight (subject to =FindVictim=)                     |
| =ACT_STAY_ZONE=  | wandering never leaves =default_zone=                                  |
| =ACT_WIMPY=      | flees when hurt; never initiates; aggression and hunting skip it       |
| =ACT_ANNOYING=   | will also attack other mobs                                            |
| =ACT_HATEFUL=    | attacks anyone it hates, on sight                                      |
| =ACT_AFRAID=     | flees anyone it fears                                                  |
| =ACT_IMMORTAL=   | natural event mob (not killable in the usual way)                      |
| =ACT_HUNTING=    | currently tracking someone (set by =SetHunting=)                       |
| =ACT_DEADLY=     | deadly poison                                                          |
| =ACT_POLYSELF=, =ACT_POLYOTHER= | a polymorphed player                                     |
| =ACT_GUARDIAN=   | guards and follows its master                                          |
| =ACT_CITIZEN=    | protects others, spreads hatred, calls for help                        |
| =ACT_HEALER=     | heals self or friends on an interval                                   |
| =ACT_NOSUMMON=   | cannot be summoned                                                     |
| =ACT_FAR_HUNT=   | hunting may cross zones                                                |
| =ACT_TRAVELING=  | currently in an animated travel                                        |
| =ACT_NO_WEAR=    | will not wear equipment it finds                                       |

* Aggression and victim choice
:PROPERTIES:
:CUSTOM_ID: aggression-and-victim-choice
:END:

=act_aggressive= (=mobact.c=): pick a victim with =FindVictim=; refuse
if the mob is below half health /and/ worse off than the victim, or if
the room is peaceful, or if the victim is stone-encased; shout or growl
(humanoid or animal); =mob_initiate= then =hit=.

=FindVictim= (=fight.c=): if already fighting, that opponent. Charmed
and wimpy mobs never pick. Otherwise every character in the room that
is not the mob itself, is awake, is visible to the mob (=CAN_SEE=), is
not sneaking, prowling or shimmered (unless already fighting), is not a
mob (unless the attacker is =ACT_ANNOYING=), and is not a player with
=PLR_NOHASSLE=. Candidates are weighted by class (fighter, cleric,
mage, thief) and a random roll picks one, skewed toward the better
target as the mob's intelligence rises.

* Memory: hatred and fear (=opinion.c=, =utils.c=)
:PROPERTIES:
:CUSTOM_ID: memory-hatred-and-fear
:END:

Each mob has an =Opinion= for hates and one for fears: a bitfield of
categories plus category values and a list of individuals with expiry.

=Hates(ch, v)= is true if =v= is on the individual list, or matches a
set category: race, sex, alignment above the "good" threshold, below
the "evil" threshold, class, or vnum. Paralysed and confused mobs hate
no one. =Fears= is the same shape.

=DevelopHatred(ch, v)= runs on every blow a mob lands
(=event_strike=): if the mob does not already hate =v=, compute the
alignment gap divided by 5 against the mob's "patience" (its current
health percentage plus a roll of ±20); when patience is lower than the
gap, =AddHated(ch, v, HOUR)= for one real hour. Low health and
opposing alignment make a mob remember you.

=spread_hatred=: once a minute, a humanoid police or citizen mob tells
every awake humanoid mob it can see in the room about each individual
it hates, so they hate them too. Reputations travel through a town.

=DecayHatred=: every 20th think, expired entries drop off.

* Hunting: chasing across rooms (=MobHunt=, =mobact.c=)
:PROPERTIES:
:CUSTOM_ID: hunting-chasing-across-rooms
:END:

=SetHunting(mob, target)= (=utils.c:304=) sets =ACT_HUNTING= with a
persistence budget of the mob's level plus 1 to 50 steps and remembers
=old_room=. It is called when:

- a player flees from the mob (=do_flee=, =offensive.c:631=)
- a fear spell drives a mob off (=magic.c:4269=)
- a mob special asks for it (=spec_mob.c:5941=)
- the game marks a player as hunted by a set of vnums or for notoriety
  (=SetHuntedBy=, =SetHunted=, =utils.c:382,403=)

Each think while hunting: =persist--=; at zero, stop and clear the
flag. Otherwise find the quarry (the first hated individual still in
the game), and unless =ACT_FAR_HUNT=, give up if it is in another
zone. Take one step along a shortest path to it (=choose_exit=,
bounded at 2,000 rooms, humanoid-aware for doors), avoiding
immediately doubling back. On reaching the quarry, attack if the mob
can see it and still hates it, unless stone-encased or the room is
peaceful. Hunting is therefore persistent for a bounded number of
rooms, roughly the mob's level in steps, and zone-bound by default.

* Wandering (=mobile_wander=)
:PROPERTIES:
:CUSTOM_ID: wandering
:END:

Every 5th think for non-sentinels: pick a random exit index 0 to 15,
walk the exit list that far, give up if there is no such exit, refuse
no-mob and death rooms, require the mob to be standing, require the
exit to be passable (humanoids can open doors, others cannot), avoid
walking straight back the way it came two thirds of the time, and stay
in =default_zone= if =ACT_STAY_ZONE=. Guardians do not wander.

* Grouping, assisting, citizens
:PROPERTIES:
:CUSTOM_ID: grouping-assisting-citizens
:END:

- =group_with=: a mob loaded with a leader vnum joins that leader as a
  follower when it sees it, and gets =AFF_GROUP=.
- =aid_friends=: a standing mob joins any fight in its room on the side
  of a mob of its own vnum or group, if it can fight the opponent.
  Charmed mobs do not.
- =ACT_CITIZEN= and police: besides spreading hatred, a fighting
  humanoid citizen may call for help every 10th think, and
  =IS_POLICE= / =IS_CITIZEN= gate who listens.

* In a fight
:PROPERTIES:
:CUSTOM_ID: in-a-fight
:END:

Combat is per attacker: each fighter has its own =EVT_STRIKE= chain
timed by =calc_speed= ([[file:game-engine-loop.org::#the-event-system][engine, "The event system"]]). On each of a mob's
strikes, =DevelopHatred= first, then =mob_attack= rolls against the
mob's skill and spell lists for a special attack and, failing that, a
plain =hit=. Independently, the think's =act_fight= branch lets
humanoids cast (=act_caster=) or call for help every 10th think, wakes
a sleeping mob on a resistance check, and stands a sitting one.

=ACT_WIMPY= mobs flee when hurt (=fight.c:1765,2236=) and are skipped
by aggression and hunting. A fleeing player triggers =SetHunting= on
the mob left behind.

* Special procedures (=spec_mob.c=, =spec_assign.c=)
:PROPERTIES:
:CUSTOM_ID: special-procedures
:END:

117 C functions, bound to mob vnums at boot by a table in
=spec_assign.c= ("Assigning function pointers: Mobiles."; a duplicate
vnum logs "already assigned"). There is no scripted mob-program
language in the current source; AMPL is a separate tool. A special is
=func(type, mob, actor, argument, cmd)= and returns true to say it
handled the event. Trigger types (=h/const.h:1495=):

| type            | when                                                               |
|-----------------+--------------------------------------------------------------------|
| =SPEC_IDLE=     | the mob's own think                                                |
| =SPEC_FIGHT=    | every third think while fighting                                   |
| =SPEC_CMD=      | a player in the room issued any command; runs before the command  |
| =SPEC_MOVE=     | same, for movement commands (direction, =go=, =enter=)             |
| =SPEC_OPP_DIES= | its opponent died                                                  |
| =SPEC_INIT=     | creation                                                           |
| =SPEC_DEATH=    | its own death (=fight.c:1927,2400=)                                |

For a player's command, =special()= (=interpreter.c:314=) tries, in
order: the room's special, each item the player wears, each item the
player carries, each mob in the room, each object on the floor. The
first to return true consumes the command. This is the only way a mob
reacts to a player instantly, and it reacts to what the player does,
not to their presence. Shopkeepers, guildmasters, guards, bankers,
receptionists and the like are all specials.

* Sounds
:PROPERTIES:
:CUSTOM_ID: sounds
:END:

Every 60 s (=PULSE_AUDIO=, =MakeSound=), each awake mob with a
=sounds= string has a 1 in 6 chance of making it in its room, and
objects with noises do likewise.

* Death
:PROPERTIES:
:CUSTOM_ID: death
:END:

=die= → =raw_kill= → =make_corpse=: the prototype's =num_destroyed=
is incremented (=fight.c:655=) and =game_count= decremented on extract
(=handler.c:3990=), equipment and inventory go to the corpse, the
special gets =SPEC_DEATH=, hunters and haters forget it, and the
=EVT_MOBILE= chain ends because the next =add_event= is refused for a
dead character. The zone's next reset reloads it if it is below its
limit.

* Immortal tools
:PROPERTIES:
:CUSTOM_ID: immortal-tools
:END:

- =show mob <name>= / =show mob lo hi=: prototype search by keyword or
  range; =show mob limited= shows limits and counts; =show mob kills=
  sorts by =num_destroyed=.
- =show rank=: mobs ranked.
- =mwhere <name>=: every instance and where it is.
- =switch=: become a mob; the think's debug =sendf= lines then show
  what it is deciding.
- =stat=, =set= on mobs as on players.

* Quirks and things to know
:PROPERTIES:
:CUSTOM_ID: quirks-and-things-to-know
:END:

- Aggression is checked every 4th think, so an aggressive mob takes 1
  to 4 seconds to notice you, depending on where its phase is.
- Hatred lasts a real hour and spreads; a bad reputation in a town is
  real and times out on its own.
- Hunting persistence is in steps, not time; a level-30 mob follows
  for 31 to 80 room-steps and then stops wherever it is, far from home.
- Count Buntavic (vnum 112100) hunts at half speed by a hardcoded
  coin flip (=mobact.c=).
- A mob's think and its strike chain run on separate events; a mob can
  be striking every second and wandering every 5th think only because
  =act_state= checks =fighting= before =wander=.
- The mob think, like everything else, stretches under load; nothing
  catches up.
- Mobs get the same per-tick regen event as players, so a fled-from mob
  is healing while it hunts you.

* Clarifications (2026-10-02)
:PROPERTIES:
:CUSTOM_ID: clarifications
:END:

** There is no "mob pass" in the engine
:PROPERTIES:
:CUSTOM_ID: there-is-no-mob-pass-in-the-engine
:END:

The engine never iterates mobs. Each mob owns exactly one =EVT_MOBILE=
event on the wheel ([[file:game-engine-loop.org::#the-event-system][engine, "The event system"]]); when it fires
it runs =act_state= once and reschedules itself: after the mob's
remaining =wait= if it is lagged, else one second (=WAIT_SEC=, 100
pulses), or always one second for =ACT_SPEC= mobs so their special
keeps running. In a given pulse only the mobs whose events sit in that
slot think, about one percent of them; over one second every mob
thinks once. The phase each mob thinks on is fixed by its random
1..1,200 pulse first delay at load and only shifts when lag delays it.

Per think, in order: =pulse_count++=; =act_state= (the priority list
above); =wait -= WAIT_SEC=, clamped at 0; reschedule. Blows are not
part of the think: a fighting mob also has its own =EVT_STRIKE= chain
at its weapon speed, independent of the think phase.

** Swarms
:PROPERTIES:
:CUSTOM_ID: swarms
:END:

Two mechanisms. A prototype with =group_with= set attaches to that
leader vnum as a follower on sight and fights its fights. Independently
=aid_friends= makes any standing mob join a fight in its room on the
side of a mob with the same vnum or in the same group. "Friend" means
only that: same vnum or same group; there is no friend list.

** =act_aggressive= vs =act_fight=
:PROPERTIES:
:CUSTOM_ID: act-aggressive-vs-act-fight
:END:

=act_aggressive= decides to /start/ a fight and runs only when the mob
is not fighting: =FindVictim=, the worth-it and peaceful checks, shout
or growl, =mob_initiate=, =hit=. =act_fight= runs only /while/ fighting
and is not the blows: wake if asleep (resistance check), stand if
sitting, and for humanoids every 10th think a citizen may shout "Help!
Guards! <name> is a murderer!" and =CallForGuard=, or a scholar-class
mob may cast at its opponent (=act_caster=). A warrior mob's =act_fight=
does nothing; its strikes are its fight.

** A hunting step
:PROPERTIES:
:CUSTOM_ID: a-hunting-step
:END:

One room through a real exit. =choose_exit= is a breadth-first search
over up to 2,000 rooms that returns the exit from the mob's current
room lying on a shortest path to the quarry; the mob walks through it
like a player (humanoids open doors). No teleporting. One step per
think, so about a room per second, until the step budget runs out.

** Citizens and police
:PROPERTIES:
:CUSTOM_ID: citizens-and-police
:END:

A citizen is any mob whose builder set =ACT_CITIZEN=: a townsperson
that calls guards when attacked, spreads its hatreds to other citizens
once a minute, and protects others. Police are a hardcoded list of
guard vnums (=IS_POLICE=, =h/utils.h:409=) that answer the call.
Together they make a town defend itself and remember offenders.

** Hate without attack
:PROPERTIES:
:CUSTOM_ID: hate-without-attack
:END:

Every mob accumulates hatred from being hit, but only =ACT_HATEFUL=
mobs attack on sight because of it. Others use hatred to choose targets
and to decide whether to hunt when a player flees. A shopkeeper
remembers being hit without becoming an attacker; a guard flagged
hateful comes for the player on sight.

** Builders' view
:PROPERTIES:
:CUSTOM_ID: builders-view
:END:

A mob is a text block in =world/MOB/<zone>.mob= (names, descriptions,
race, level, alignment, stats, attacks per round, armour by body part,
spell and skill lists, immunities, affects, and the =act= flag list
such as =act { sentinel, npc, aggressive }=), plus the zone's reset
commands that say where it loads and what it carries. The world
compiler produces =mob.out=; the game loads it at boot. Tuning is edit,
recompile, reset the zone, observe: =switch= into the mob to see its
debug thoughts, =mstat=, =set= fields live. No in-game mob editor, no
scripting in current =src=; behaviour beyond the flags is a C special
procedure bound to the vnum.

** No instance identity
:PROPERTIES:
:CUSTOM_ID: no-instance-identity
:END:

A vnum names the prototype. Three wolves loaded by a zone are three
=char_data= with the same vnum and nothing to tell them apart but their
memory address, which is reused after death. Hatred, hunting and
grouping hold pointers validated against the live list before use, and
"same vnum = friend" stands in for the identity the game lacks. Objects
are the same: a saved sword in a player file is a copy of its fields,
not a reference. A rewrite must give every mob and object instance an
id at creation (see [[file:../SUMMARY.md][SUMMARY.md]] §16, ids, and [[file:objects.org::#prototype-and-instance][objects, "Prototype and instance"]]).
